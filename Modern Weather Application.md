**🌤️ Weather Forecast App** is the complete English-language guide to building a real weather forecast app with HTML, CSS, and JavaScript. Learn how to fetch live data from a weather API, handle geolocation, display current conditions and 7-day forecasts, cache responses, and gracefully handle errors — with runnable code and a clean UI. Built for frontend developers, bootcamp students, and anyone who wants a real API project in their portfolio. **Completely free.** No signup. No paywall. No hidden chapters.

## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **No data** | Check API key |
| **Geolocation blocked** | Request on click |
| **CORS error** | Use server proxy |
| **Wrong units** | Check query param |
| **Stale data** | Clear cache |
| **Blank forecast** | Check API response |
